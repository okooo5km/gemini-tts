# 语音控制速查

以下多行命令按 Bash 展示；Windows PowerShell 的解释器、参数数组及 UTF-8 文件示例见 [跨平台指南](platforms.md)。请以实际技能安装路径定位脚本。

查看：`python3 ~/.agents/skills/gemini-tts/scripts/tts.py controls`，离线可用。

| 想控制什么 | 参数 | 示例值 |
| --- | --- | --- |
| 音色身份 | `--voice` | `Kore` 或 `Puck` |
| 情绪 | `--emotion` | `温暖、鼓励，带一点笑意` |
| 语速节奏 | `--pace` | `前半句稍快，后半句放慢` |
| 语言口音 | `--accent` | `自然普通话` |
| 表达方式、音量 | `--delivery` | `像朋友聊天，轻声说，避免播音腔` |
| 词语重音 | `--emphasis` | `强调“不是只有”，结尾笃定` |
| 韵律起伏 | `--prosody` | `轻重和语调随情绪自然变化，不要每句套同一种起伏` |
| 个别词延长 | `--lengthening` | `感慨或犹豫时适当拉长个别词，不固定拖尾音` |
| 停顿方式 | `--pauses` | `跟随思考和语义，长短自然，不机械按标点停顿` |
| 其他表演要求 | `--style` | `前半句像纠正误解，后半句给人信心` |

除了 `--voice`，以上都是自然语言指引，脚本会合并进 Google 的 `speech_metadata.style`，不是独立的模型参数。可以只用一个，也可以组合；避免互相矛盾。它们不提供精确的倍速、分贝或毫秒保证，实际表现以试听为准。控制项不会自动加入旁白正文。

## 自然表达：让情绪带动变化

普通话任务默认用自然普通话，保持词语读音正确。自然感来自具体情绪和交流对象：犹豫时某个词可能延长，想起一件事时可能短暂停顿，解释重点时可能加重；这些变化不必每次完全相同，也不应由脚本随机插入。

先给出一个清楚的场景，例如 `--delivery '给熟悉的朋友发语音，随口分享今天的事'`。需要进一步调节时再加：

```bash
--emotion '轻松，想到有趣的地方带一点笑意' \
--prosody '让轻重和语调随内容变化，保留随口表达的不均匀节奏' \
--lengthening '情绪需要时自然延长个别词，其余正常说，不刻意拖尾音' \
--pauses '跟随思考和语义自然停顿，不让每处停顿一样长'
```

这些参数全部合并为风格提示；没有新增随机数、逐字时长或音高控制接口，不能保证每次变化的幅度。不要同时要求“完全均匀”与“随性变化”。精确某处的短停顿可用下方标签；一般自然聊天优先让模型处理节奏。除非用户允许改写，不为自然感擅自添加“嗯、啊”或更换词句。

## 某个位置停顿或发声

在 `--text`、文本文件或对话的 `text` 中直接放标签，原样传给模型：

- `<short pause>`：短暂停顿，例如 `不是只有伟大的艺术家，<short pause>才能创造出好的作品。`
- `<sigh>`：叹气，例如 `<sigh>这次没有成功，明天再试一次。`
- `<cough>`：咳嗽，例如 `不好意思，<cough>我们继续。`

这些是 Google 文档给出的标签示例，不是 SSML。不要把“（温柔地）”之类舞台说明混进正文，它们可能被读出来。笑意用 `--emotion '带一点笑意'`，无需为了自然感强行插入笑声或叹气。更多标签先查官方提示指南，不编造未验证的标签。背景音乐、掌声和环境音不属于这里的发声控制。

## 可直接改的例子

```bash
python3 ~/.agents/skills/gemini-tts/scripts/tts.py generate \
  --text '不是只有伟大的艺术家，<short pause>才能创造出好的作品。' \
  --voice Kore \
  --emotion '温暖、鼓励，带一点笑意' \
  --pace '像朋友聊天，不刻意拖长，后半句略放慢' \
  --accent '自然普通话' \
  --delivery '对一个人说话，避免朗诵腔和广告腔' \
  --emphasis '强调“不是只有”，后半句笃定地落下' \
  --out /absolute/existing/directory/encouragement.wav
```

先加 `--dry-run` 可以检查文本和合并后的指引，不发起生成。调用者也可以只描述想要的效果，由技能映射到这些参数；普通朗读不必填写全部控制项。

## 对话的逐段控制

`--dialogue` JSON 中每个 turn 可提供 `style`，覆盖该段继承的全部命令行指引；省略时继承命令行合并后的风格。每段 `text` 都可包含上述标签。角色音色由 `speakers[].voice` 设置。
